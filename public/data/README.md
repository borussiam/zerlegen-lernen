# Pre-parsed German vocabulary data

`pre-parsed-words.json` is generated by `npm run data:build`. Its definitions,
articles, decompositions, links, and Wiktionary examples come from German entries
on [English Wiktionary](https://en.wiktionary.org/). Generated fallback examples
are explicitly marked with `source: "generated"`.

Candidate lemmas, CEFR labels, and frequency ranks are selected from the German
deck in [Language-Learning-decks](https://github.com/vbvss199/Language-Learning-decks),
which attributes its frequency data to
[wordfreq](https://github.com/rspeer/wordfreq). The build uses a pinned source
revision recorded in the JSON metadata. Candidate data is only used to choose
which entries to parse; dictionary fields are not copied from that deck.

Prefixes and suffixes deliberately use `level: null` and are excluded from
random-word selection. Words parsed after an uncached search are added to the
runtime vocabulary overlay (`data/runtime-vocabulary.json` in writable local
environments). Their provisional A2–B2 level is inferred conservatively from
word length, decomposition complexity, and any known component levels; it is
not an official CEFR classification.
